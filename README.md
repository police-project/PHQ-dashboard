# 🚔 PHQ Complaint Dashboard

This project is a web-based dashboard to monitor and analyze complaint data using CSV files.

---

## 📊 Features
- View all complaints in table format
- Filter complaints by category or status
- Track complaint status (Pending / Resolved)
- Simple and clean UI dashboard

---

## 🛠️ Tech Stack
- Frontend: Next.js / React
- Backend: (optional later)
- Database: CSV file (for now)
- Deployment: Vercel (recommended)

---

## 📁 Project Structure
PHQ-dashboard/

---

## 🚀 How to Run Project

### 1. Clone Repository
git clone https://github.com/police-project/PHQ-dashboard.git
cd PHQ-dashboard

### 2. Install Dependencies
cd frontend
npm install

### 3. Run Project
npm run dev

### 4. Open in Browser
http://localhost:3000
